# Dataset attribution

The experimental sample comes from **CESNET-TimeSeries24 v1**, by Josef Koumar, Karel Hynek, Tomáš Čejka and Pavel Šiška (2024), published by Zenodo: https://doi.org/10.5281/zenodo.13382427.

The dataset is licensed under **Creative Commons Attribution 4.0 International**: https://creativecommons.org/licenses/by/4.0/. The dataset record also requests citation of Koumar et al., *CESNET-TimeSeries24: time series dataset for network traffic anomaly detection and forecasting*, Scientific Data 12, 338 (2025), https://doi.org/10.1038/s41597-025-04603-x.

The local submission bundle contains only the institution 0 ten-minute sample and timestamp mapping, extracted and renamed without changing their contents. Features, exclusions, windows, forecasts and simulation results are project-derived transformations. See `dataset_notes.md`, `data/prepared/preparation_config.json` and `research_notes.txt` for the transformation policies, provenance and checksums. These transformations are not endorsed by the dataset authors.

The dataset license applies to the included source data; it does not assign a license to the project's original code.

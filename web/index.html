The methodology

From recorded traffic
to a capacity decision.

This experiment asks whether historical traffic can support proactive bandwidth allocation. The website lets you inspect the saved predictions and their tradeoffs.

A 60-minute forecast estimates one 10-minute interval ending an hour ahead. It is not the total usage over the coming hour.

  1. Measure the traffic

    Institution 0 from CESNET-TimeSeries24 supplies the recorded byte volumes. Each observation becomes an average rate in Mbps over its 10-minute interval.

  2. Use the preceding three hours

    LSTM, GRU and Transformer models use 18 observations, calendar features and rolling statistics. Persistence repeats the latest value; the moving average uses the latest four.

  3. Evaluate on later observations

    Chronological training, validation and test periods keep future targets separate. Scaling uses training data only; windows cannot cross excluded periods or timestamp breaks.

  4. Allocate and measure the tradeoff

    At the 10-minute horizon, a safety margin is applied to the nonnegative forecast. The reactive policy uses the same margin on the latest observed demand. Both unmet demand and unused capacity matter.

Data definitions, evaluation boundaries and limitations

Nominal recorded Mbps = n_bytes × 8 ÷ (600 × 1,000,000). Recorded traffic includes both directions and is not physical link utilization or a user's download speed.

The 70/15/15 split points are set on the original timeline before exclusions. Eligible windows therefore need not follow those exact proportions. MAPE uses positive targets. One institution and one fixed seed limit generalisation.

Shortfall volume in decimal MB = deficit Mbps × 600 ÷ 8 for each interval. None of the tested margins met the 1% validation shortfall target; the default 20% is a fallback.

Bandwidth allocation is an offline capacity-pool simulation. This page replays saved results; it does not collect live traffic or run new model inference. Cloud and data-center use would require separate validation.
